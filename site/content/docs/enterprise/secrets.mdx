# シークレット管理

Favnir は `fav.toml` の `[secrets]` セクションで AWS Secrets Manager または HashiCorp Vault からシークレットを取得し、実行時に環境変数として注入します。
ソースコードにシークレットを直接埋め込む必要はありません。

## 設定例

```toml
[secrets]
provider = "aws-secrets-manager"
region   = "ap-northeast-1"

[secrets.bindings]
SNOWFLAKE_PASSWORD = "prod/snowflake/password"
KAFKA_API_KEY      = "prod/kafka/api-key"
```

## 対応プロバイダ

| プロバイダ | 設定値 |
|---|---|
| AWS Secrets Manager | `aws-secrets-manager` |
| HashiCorp Vault | `vault` |

## シークレット注入

```bash
fav run pipeline.fav --inject-secrets
```

`--inject-secrets` フラグを指定すると、`[secrets.bindings]` で定義したシークレットが
環境変数として注入された状態でパイプラインが実行されます。

## シークレット管理コマンド

```bash
# 登録済みシークレットの一覧表示
fav secrets list

# シークレットのローテーション
fav secrets rotate SNOWFLAKE_PASSWORD
```
