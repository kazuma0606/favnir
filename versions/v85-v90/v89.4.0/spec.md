# Spec: v89.4.0 — `fav infer --from sap --entity <name>` コマンド

## Background

v89.3.0 で E2E パイプライン（`pipeline.fav`）に 4 業務シナリオが揃った。
本バージョンでは開発者が SAP OData エンティティから Favnir 型定義を素早く生成できる
`fav infer --from sap --entity <EntitySetName>` コマンドを追加する。

既存の `fav infer --from snowflake --table <name>`（v10.8.0）・`fav infer --from delta`（v27.7.0）
と同じ `cmd_infer_*` ファミリーパターンで実装する。

## Goals

1. `fav/src/driver.rs` に `cmd_infer_sap(entity: &str, out_path: Option<&str>)` 関数を追加する
   - SAP OData エンティティ名から Favnir 型定義テンプレートを生成する
   - `A_SalesOrder` → `SalesOrder` のように `A_` プレフィックスを除去して型名を生成
   - 生成ヘッダー: `// auto-generated by fav infer --from sap --entity <entity>`
   - 出力形式: `type <TypeName> = { ... }` （代表的 SAP 共通フィールド付きテンプレート）
2. `fav/src/driver.rs` の `mod v89400_tests` に 2 件のテストを追加する

## API / Syntax Examples

```bash
# SAP エンティティから Favnir 型テンプレートを生成
$ fav infer --from sap --entity A_SalesOrder
// auto-generated by fav infer --from sap --entity A_SalesOrder
// Review and adjust before use.
type SalesOrder = {
    object_key: String,
    created_at: Option<String>,
    changed_at: Option<String>
}

$ fav infer --from sap --entity A_BusinessPartner
// auto-generated by fav infer --from sap --entity A_BusinessPartner
// Review and adjust before use.
type BusinessPartner = {
    object_key: String,
    created_at: Option<String>,
    changed_at: Option<String>
}
```

## 型名変換ルール

| 入力エンティティ名 | 生成型名 |
|---|---|
| `A_SalesOrder` | `SalesOrder`（`A_` プレフィックス除去） |
| `A_BusinessPartner` | `BusinessPartner` |
| `SalesOrder` | `SalesOrder`（プレフィックスなし → そのまま） |
| `my_entity` | `my_entity`（小文字 → そのまま） |

ルール: 文字列が `A_` で始まる場合のみ先頭 2 文字を除去する。それ以外はそのまま型名に使用。

## Success Criteria（Rust テストで担保）

- `cmd_infer_sap_entity_exists`:
  `fav/src/driver.rs` に `"cmd_infer_sap"` という文字列を含む
- `fav_infer_from_sap_generates_favnir_type`:
  `driver.rs` のソースコードに文字列 `"SalesOrder"` が含まれることを確認する
  （`cmd_infer_sap` の実装例として `SalesOrder` 型名が関数内に現れることを検証）
- `cargo test` で 4,027 tests, 0 failures（4,025 + 2）

## Files to Modify

| ファイル | 変更種別 |
|---|---|
| `fav/src/driver.rs` | `cmd_infer_sap` 関数追加 + `mod v89400_tests` 追加 |

**前提確認**:
- `cmd_infer_snowflake`（v10.8.0）・`cmd_infer_delta`（v27.7.0）が実装済みで参照パターンとして使用できる
- `write_infer_output` は `driver.rs` 内プライベート関数（`pub` なし）。`cmd_infer_sap` も同ファイル内に追加するため呼び出し可能
- 本バージョンでは実際の OData $metadata XML パースは行わない（テンプレート生成のみ）
- WASM ガード不要: `cmd_infer_sap` は外部通信なし（`cmd_infer_snowflake` と異なり `#[cfg(not(target_arch = "wasm32"))]` は不要）
- `clippy::collapsible_str_replace`: `.replace('\n', "").replace('\r', "")` の連鎖に `#[allow]` が必要（`cmd_infer_delta` と同様）

**Note**: CHANGELOG / MILESTONE / site MDX 更新は v90.0.0 宣言バージョンでまとめて実施する（本バージョンは対象外）
**Note**: Cargo.toml のバージョンは v90.0.0 宣言まで `89.0.0` のまま維持する。
