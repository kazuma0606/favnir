# Favnir 2.0 Showcase

v70〜v74 の全機能を統合したデモパイプライン。

## 実行手順

```bash
fav run pipeline.fav
```

## 機能一覧

- 依存型（Vec<Float>[1536]）: v71.x
- データコントラクト + SLA: v72.x
- マルチテナント設定: v74.2.0
- パイプラインスケジューリング: v74.5.0
- Rune マーケットプレイス: v74.1.0
- セキュリティ監査: v74.6.0
- Rune 品質基準: v74.7.0

## ファイル構成

| ファイル | 内容 |
|---|---|
| `pipeline.fav` | メインパイプライン（全フェーズ機能を網羅） |
| `fav.toml` | マルチテナント + SLA + スケジュール設定 |
| `rune.toml` | カスタム Rune 依存定義 |
| `contract.fav` | データコントラクト定義 |
| `quality.fav` | 品質スコアリングパイプライン |
