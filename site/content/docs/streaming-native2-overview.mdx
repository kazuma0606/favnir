# Streaming Native 2.0

> 「ウィンドウはイベントを時間で区切り、ウォーターマークは遅延を許容し、
>  チェックポイントは障害から瞬時に回復する。
>  CEP はイベントの流れからパターンを検出する。
>  Favnir はリアルタイムデータの言語になった。」

v55.x Streaming Native 2.0 は、v41〜v52 で積み上げたウィンドウ・CEP・並列基盤を統合し、
**Exactly-once・Stateful・Replay を備えた本番品質のストリーム処理基盤**を完成させたマイルストーンです。

## クイックスタート

### fav.toml 設定

```toml
[stream]
buffer_size = 1000
delivery = "exactly-once"
checkpoint_interval_sec = 10
checkpoint_store = "s3://my-bucket/checkpoints"
session_gap_sec = 30
watermark_max_late_sec = 5
```

### Stateful パイプライン例

```favnir
stage CountEvents: Stream<Event> -> Stream<Int> = |event| {
  bind count <- State.get_or_default("total", 0)
  bind _ <- State.set("total", count + 1)
  Ok(count + 1)
}
```

### CEP パターン例

```favnir
fn is_start(e: Event) -> Bool { e.type == "start" }
fn is_end(e: Event) -> Bool { e.type == "end" }

stage DetectPattern: Stream<Event> -> Stream<List<Event>> = |events| {
  bind preds <- collect {
    yield is_start;
    yield is_end;
  }
  Ok(CEP.sequence(events, preds))
}
```

### チェックポイント操作

```bash
# チェックポイント一覧
fav checkpoint list

# 再開
fav run pipeline.fav --resume-from 2026-07-23T09:10:00Z
```
