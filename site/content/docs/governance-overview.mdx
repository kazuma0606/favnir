## Governance & Deployment at a Glance

Favnir's Governance & Deployment suite gives enterprise teams full control over how pipelines are deployed, monitored, and governed:

- **Blue/Green & Canary**: Deploy new pipeline versions without downtime. Route traffic gradually and roll back instantly.
- **HA**: Run multiple replicas with automatic failover. Health checks via `/healthz` ensure reliability.
- **Schema Migration**: Version-controlled schema changes applied safely across dev, staging, and prod.
- **Data Catalog**: Discover and register pipeline outputs across your organization.
- **Policy-as-Code**: Define governance rules as Favnir code. Violations surface as compiler errors (`E0426`).
- **Multi-Environment**: A single pipeline runs across environments via `--env` and `fav.toml [env]` sections.

## Quick Start

```bash
# Deploy with Blue/Green strategy
fav deploy pipeline.fav --strategy blue-green --env prod

# Run with High Availability
fav run pipeline.fav --ha --replica 3

# Check policy compliance
fav policy check pipeline.fav --policy-dir ./policies/

# Publish outputs to Data Catalog
fav catalog push pipeline.fav --env prod
```
