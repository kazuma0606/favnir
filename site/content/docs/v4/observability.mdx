# Observability 2.0（Favnir 4.0）

Sprint 4 で導入した可観測性機能を解説します。

## PipelineMetrics / StageMetrics

`StageMetrics` はステージ単位の実行統計（duration_ms / rows_processed /
rows_failed）を保持します。`PipelineMetrics` はステージリストと全体統計を集約します。

```favnir
bind stage <- StageMetrics {
    stage_name: "load_stage",
    duration_ms: 42,
    rows_processed: 1000,
    rows_failed: 0,
}
bind metrics <- PipelineMetrics {
    pipeline_name: "my-pipeline",
    stages: List.of(stage),
    total_duration_ms: 42,
    started_at: "2026-08-22T00:00:00Z",
}
```

## AlertRule / evaluate_alert_rules

`AlertRule` は `AlertThreshold`（metric / operator / value）と severity を持ちます。
`evaluate_alert_rules` でメトリクスに対してルールを評価し `AlertFiring` リストを返します。

```favnir
bind rule <- AlertRule {
    name: "latency_alert",
    threshold: AlertThreshold {
        metric: "total_duration_ms",
        operator: ThresholdOp.GreaterThan,
        value: 5000.0,
    },
    severity: AlertSeverity.Warning,
    message: "Pipeline latency exceeded threshold",
}
bind alerts <- evaluate_alert_rules(List.of(rule), metrics, "2026-08-22T00:00:00Z")
```

## SloTarget / SloMeasurement / compute_slo_status

`SloTarget`（name / objective_pct / window_hours）と `SloMeasurement`
（good_events / total_events / window_hours）から `compute_slo_status` で
`SloStatus` を取得します。

```favnir
bind slo_tgt  <- SloTarget { name: "my-slo", objective_pct: 99.0, window_hours: 24 }
bind slo_meas <- SloMeasurement { good_events: 990, total_events: 1000, window_hours: 24 }
bind slo      <- compute_slo_status(slo_tgt, slo_meas)
```

## HealthDashboard / format_health_dashboard

`compute_pipeline_health` でパイプラインの総合健全性（`PipelineHealth`）を算出し、
`HealthDashboard` にまとめて `format_health_dashboard` で文字列出力します。

```favnir
bind health    <- compute_pipeline_health(metrics, alerts, slo, 0.95)
bind dashboard <- HealthDashboard {
    pipelines: List.of(health),
    generated_at: "2026-08-22T00:00:00Z",
}
bind output    <- format_health_dashboard(dashboard)
```
