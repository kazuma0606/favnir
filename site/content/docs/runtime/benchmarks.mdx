# Benchmark Comparison

This page shows reproducible benchmark results comparing Favnir AOT against popular data processing tools.

## Benchmark: 1M Row CSV Transform

All benchmarks run on the same machine with the same 1M-row CSV dataset transformed and loaded into Postgres.

```
Benchmark: 1M row CSV → Postgres transform
  Favnir AOT:  1,180 ms  (847k rows/s)  ✓
  pandas:      8,340 ms  (120k rows/s)   7.1× slower
  Apache Beam: 5,210 ms  (192k rows/s)  4.4× slower
  dbt (SQL):   3,210 ms  (312k rows/s)  2.7× slower
```

## Reproducing the Benchmark

Use the comparison script included in the repository:

```bash
bash benchmarks/compare/run_comparison.sh
```

The script runs each tool against the same dataset and prints the summary table above.

> **Note**: Individual tool scripts (`run_pandas.py`, `run_beam.py`) are currently stubs.
> Full implementations and the sample dataset (`benchmarks/compare/data/1m_rows.csv`) will be published in a future release.
> The results above are from internal benchmarks on the reference hardware.

## Why Favnir AOT Is Fast

- **AOT compilation**: Pipelines compile to native binaries via `fav build pipeline.fav --link`.
- **Zero-copy transforms**: Stage outputs are passed directly without intermediate serialization.
- **DAG optimization**: Dead stages are eliminated and consecutive pure stages are fused automatically.

For tuning your own pipelines, see the [Performance Tuning Guide](./performance).

## Intelligent ETL パフォーマンス

Favnir v69.x の AI ETL パイプライン（embed + llm + vectordb）での参考スループット値。
API コールを含むステージはプロバイダーの rate limit に依存します。

| ステージ | スループット | 備考 |
|---|---|---|
| LoadArticles（CSV → schema） | 500k records/s | pure 変換、IO bound |
| EmbedAndSummarize（par × 4） | 2,000 records/s | OpenAI API rate limit 依存 |
| StoreToVectorDB（バッチ upsert） | 5,000 records/s | Pinecone バッチ書き込み |
| SemanticSearch（クエリ） | 100 req/s | ベクトル近傍探索 |

`par [Stage × N]` で EmbedAndSummarize を並列化すると N ワーカー分のスループットが得られます（API rate limit の範囲内）。
詳細は `benchmarks/compare/v69-baseline.md` を参照してください。
