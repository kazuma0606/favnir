# Spec: v93.6.0 — `fav infer --from sap --metadata-file <path>` CLI

## Background

v93.5.0 でリモート URL（`--metadata`）からの型推論スタブを追加した。
v93.6.0 では、ローカルの EDMX ファイルを入力源とする `--metadata-file <path>` オプションを追加する。
オフライン環境や CI パイプラインで、事前ダウンロード済みの `*.xml` ファイルから型定義を生成する用途を想定する。

## Goals

1. `infer.rs` に `infer_from_sap_metadata_file(path: &str) -> String` 関数を追加する（v93.6.0 スタブ）。
2. `cli.fav` に `--metadata-file` / `--output` フラグを追加し、`--from sap` と組み合わせて動作させる。
3. `driver.rs` に `mod v93600_tests`（2 件）を追加し、4,132 tests を達成する。

## Syntax / API

```bash
$ fav infer --from sap --metadata-file ./metadata/API_BUSINESS_PARTNER.xml \
            --output ./runes/sap-odata/generated_types.fav

$ cat ./runes/sap-odata/generated_types.fav
-- Generated by: fav infer --from sap --metadata-file
-- Source: ./metadata/API_BUSINESS_PARTNER.xml
-- NOTE: parse_edmx is a stub — full XML parsing will be added in v93.8.0+
```

## Implementation Details

### `fav/src/infer.rs`

既存の `infer_from_sap_metadata_url` の直後に追加:

```rust
/// ローカルの EDMX ファイルから Favnir 型定義文字列を生成する（v93.6.0 スタブ）
/// 完全実装は v93.8.0 以降（parse_edmx XML 解析完成後）で行う
pub fn infer_from_sap_metadata_file(path: &str) -> String {
    format!(
        "-- Generated by: fav infer --from sap --metadata-file\n\
         -- Source: {path}\n\
         -- NOTE: parse_edmx is a stub — full XML parsing will be added in v93.8.0+\n"
    )
}
```

### `fav/self/cli.fav`（4 か所）

- **6a**: `CliCmd` 型に `| CmdInferSapMetadataFile(String, String)` バリアントを追加する（`CmdInferSapMetadata` の直後）
- **6b**: `parse_infer_cmd` に `find_flag_value(rest, "--metadata-file", "")` および `find_flag_value(rest, "--output", "")` 取得を追加し、`from == "sap"` かつ `metadata_file != ""` のブランチを追加する（`--output` は `_out` として `run_infer_sap_metadata_file` に渡すが v93.6.0 スタブでは無視する）
- **6c**: `run_infer_sap_metadata_file(ctx: AppCtx, path: String, _out: String) -> Unit` スタブ関数を追加する（`run_infer_sap_metadata` の直後）
- **6d**: `main` の `match cmd` に `CmdInferSapMetadataFile(parts) => run_infer_sap_metadata_file(ctx, parts._0, parts._1)` アームを追加する（`CmdInferSapMetadata` アームの直後）
