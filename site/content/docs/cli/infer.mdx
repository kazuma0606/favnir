# fav infer

外部データソースのスキーマから Favnir 型定義を自動生成します。

```bash
fav infer --from <source> [options]
```

## SAP OData（sap-metadata）

SAP の `$metadata` エンドポイントまたはローカル EDMX ファイルから Favnir 型定義を生成します。

### リモート URL から生成する

```bash
fav infer --from sap --metadata https://my.sap.example.com/sap/opu/odata/sap/API_BUSINESS_PARTNER/$metadata \
          --out ./runes/sap-odata/generated_types.fav
```

### ローカルファイルから生成する（CI/オフライン向け）

事前にダウンロードした EDMX ファイルを入力として使用します。

```bash
fav infer --from sap --metadata-file ./metadata/API_BUSINESS_PARTNER.xml \
          --out ./runes/sap-odata/generated_types.fav
```

生成されたファイルの例:

```favnir
-- Generated by: fav infer --from sap --metadata-file
-- Source: ./metadata/API_BUSINESS_PARTNER.xml
-- NOTE: parse_edmx is a stub — full XML parsing will be added in a future version

public type BusinessPartner = {
    BusinessPartner: String,
    BusinessPartnerName: String,
    Country: String,
}
```

## オプション

| フラグ | 説明 |
|---|---|
| `--from sap` | SAP OData スキーマを入力源として使用 |
| `--metadata <url>` | `$metadata` エンドポイント URL を指定 |
| `--metadata-file <path>` | ローカル EDMX ファイルパスを指定（`--metadata` の代替） |
| `--sap-metadata <url>` | `--metadata` のエイリアス（v94.8.0〜 推奨形式） |
| `--sap-metadata-file <path>` | `--metadata-file` のエイリアス（v94.8.0〜 推奨形式） |
| `--out <path>` | 出力ファイルパス（省略時は標準出力） |

### `--sap-metadata` / `--sap-metadata-file`（v94.8.0〜 推奨）

v94.8.0 以降は `--sap-metadata` / `--sap-metadata-file` が推奨フラグ名。
`--metadata` / `--metadata-file` も引き続き動作する（後方互換）。

```bash
fav infer --from sap --sap-metadata https://my.sap.example.com/odata/v4/$metadata \
          --out ./runes/sap-odata/generated_types.fav

fav infer --from sap --sap-metadata-file ./metadata/API_BUSINESS_PARTNER.xml \
          --out ./runes/sap-odata/generated_types.fav
```

## Snowflake

Snowflake テーブルのスキーマから Favnir 型定義を生成します。

```bash
fav infer --from snowflake --table MY_DATABASE.MY_SCHEMA.MY_TABLE
```
