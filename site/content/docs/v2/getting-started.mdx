# Getting Started

Favnir を 5 分で試す。

## インストール

```bash
cargo install fav
```

## Hello World パイプライン

```favnir
stage Hello {
  bind msg <- "Hello, Favnir!"
  ctx.io.println(msg)
}
```

`fav run hello.fav` で実行する。
